# 1.22 — Карта сайта на ForkJoinPool

Многопоточно обходит сайт (`ForkJoinPool` + `RecursiveAction`, jsoup) и сохраняет список его страниц в текстовый файл с иерархией: дочерние страницы сдвинуты на одну табуляцию относительно родительских.

- учитываются только страницы того же домена — ссылки на другие сайты, поддомены, якоря (`#`) и файлы отбрасываются;
- уже посещённые страницы хранятся в потокобезопасном множестве, поэтому циклических обходов нет;
- перед каждым запросом пауза 100–150 мс.

## Запуск

```bash
mvn compile exec:java -Dexec.args="https://sendel.ru/ sitemap.txt"
```

Аргументы: `<url> [файл] [лимит страниц, 0 — без лимита] [число потоков]`. Для больших сайтов (например, lenta.ru) удобно задать лимит:

```bash
mvn compile exec:java -Dexec.args="https://lenta.ru/ lenta.txt 500"
```

Пример результата — [`sitemap.txt`](sitemap.txt).
